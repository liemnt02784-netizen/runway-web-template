# Runway × GDG on Campus — Asset Kit

Bộ asset chính thức cho cuộc thi **làm web giới thiệu câu lạc bộ**.

Repo này **không phải web mẫu**, cũng không hướng dẫn bạn làm thế nào. Nó chỉ chứa logo, màu, font và nội dung chuẩn để trang của bạn đúng bộ nhận diện. Còn lại bạn tự do làm theo cách của mình.

## Lấy kit về

Bấm **Use this template → Create a new repository** trên trang repo này để có bản riêng của bạn.

## Trong kit có gì

```
assets/logo/      Logo Runway, GDG on Campus, Khoa Công nghệ HSU
assets/images/    Ảnh hoạt động CLB
assets/icons/     Icon, favicon
assets/stickers/  File bế sticker (bản in ấn)
assets/videos/    Clip hoạt động CLB
assets/fonts/     Dự phòng, font lấy từ Google Fonts nên thường để trống
BRAND.md          Mã màu, font, quy tắc dùng logo
CONTENT.md        Nội dung chữ chuẩn về CLB
index.html        File trống để bắt đầu, xóa thoải mái
```

## Hai điều bắt buộc

1. Dùng logo và màu trong [BRAND.md](BRAND.md), không tự đổi màu hay kéo méo logo.
2. Thông tin về CLB lấy từ [CONTENT.md](CONTENT.md), không tự bịa.

Ngoài hai điều đó, làm gì cũng được.
