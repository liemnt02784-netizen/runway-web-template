# GDG on Campus HSU × Runway Club — Asset Kit

Bộ asset chính thức dùng chung cho **GDG on Campus HSU** (trước đây là GDSC HSU) và **Runway Club**, phục vụ cuộc thi **làm web giới thiệu hai câu lạc bộ**.

Repo này **không phải web mẫu**, cũng không hướng dẫn bạn làm thế nào. Nó chỉ chứa logo, màu, font để trang của bạn đúng bộ nhận diện. Còn lại bạn tự do làm theo cách của mình.

## Lấy kit về

Bấm **Use this template → Create a new repository** trên trang repo này để có bản riêng của bạn.

## Trong kit có gì

```
kit.html             Mở file này để XEM TRƯỚC toàn bộ asset, bấm vào ô là copy đường dẫn
assets/logo/         Logo Runway, GDG on Campus, Khoa Công nghệ HSU
assets/icons/ui/     67 icon giao diện (menu, lịch, địa điểm, mũi tên, code, cúp...) dạng SVG
assets/icons/social/ Icon Facebook, Messenger, Instagram, Discord, GitHub, YouTube, TikTok, Zalo, Gmail
assets/icons/tech/   Icon công nghệ 1 màu: Flutter, Firebase, Android, Gemini, Google Cloud, HTML, CSS, JS...
assets/tech-logos/   Logo công nghệ Google bản màu gốc (Flutter, Firebase, Android, Gemini, NotebookLM, Cloud, Chrome...)
assets/mascots/      Linh vật Go gopher, Dash (Flutter), Sparky (Firebase) bản 2D
assets/partners/     Logo 13 app/sản phẩm của Mikademy và thành viên, logo P2Game
assets/images/       Ảnh hoạt động CLB + og-cover.jpg (ảnh hiện khi chia sẻ link)
assets/events/       Ảnh sự kiện đã cắt bo góc, đặt vào thẻ là xong
assets/badges/       Huy hiệu Info Session
assets/decor/        Hình trang trí kiểu Google: tròn, vòng, sao, dấu cộng, sóng, zigzag... (4 màu)
assets/favicon/      gdg/ và runway/: favicon.ico, apple-touch-icon, icon 512 cho từng CLB
assets/stickers/     File bế sticker (bản in ấn)
assets/videos/       Clip hoạt động CLB
assets/fonts/        Dự phòng, font lấy từ Google Fonts nên thường để trống
BRAND.md             Mã màu, font, quy tắc dùng logo, cách dùng icon
index.html           File trống để bắt đầu, xóa thoải mái
```

Không biết file nào nằm ở đâu? Mở **`kit.html`** bằng trình duyệt (hoặc Live Server), gõ tên vào ô tìm kiếm.

## Một điều bắt buộc

Trang của bạn giới thiệu **cả hai CLB**: dùng logo, màu và font của từng bên theo [BRAND.md](BRAND.md) (GDG dùng Google Sans và 4 màu Google, Runway dùng Maven Pro và gradient xanh). Không tự đổi màu hay kéo méo logo.

Ngoài điều đó, làm gì cũng được.
