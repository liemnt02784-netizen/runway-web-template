# Asset

Toàn bộ hình ảnh được phép dùng cho cuộc thi nằm trong các thư mục dưới đây.

```
logo/      Logo Runway, GDG on Campus, Khoa Công nghệ HSU
images/    Ảnh hoạt động CLB (Welcome Day, DevFest, Build with AI...)
icons/     Icon SVG: ui/ (giao diện), social/ (mạng xã hội), tech/ (công nghệ)
tech-logos/ Logo công nghệ Google bản màu
mascots/   Linh vật 2D (Go, Dash, Sparky)
partners/  Logo app Mikademy, P2Game
events/    Ảnh sự kiện đã bo góc, posters/ là poster + standee Build with AI 2026
badges/    Huy hiệu
decor/     Hình trang trí kiểu Google
favicon/   gdg/ và runway/: favicon, apple-touch-icon cho từng CLB
stickers/  File bế sticker các ban trong CLB, icon công nghệ (bản in ấn)
fonts/     Dự phòng (font Maven Pro lấy từ Google Fonts, không cần file)
videos/    Clip hoạt động CLB, dùng làm nền hero hoặc chèn giới thiệu (không bắt buộc dùng)
```

## Lưu ý về dung lượng

Ảnh nên nén dưới 300KB mỗi tấm, ảnh nền dưới 500KB. Ảnh chụp từ máy ảnh thường nặng 5–8MB, tải trang sẽ rất chậm trên 4G.

**Video trong `videos/` khá nặng (9–20MB/clip).** Clone cả repo sẽ hơi lâu. Nếu chỉ cần ảnh và logo thì có thể tải riêng từng file qua GitHub thay vì clone toàn bộ. Nếu dùng video trong trang, đừng nhúng nguyên bản — nén nhỏ lại hoặc chỉ dùng làm poster/thumbnail, không thì trang sẽ tải rất chậm.
